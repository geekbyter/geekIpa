# geekIpa

一款**无广告、无弹窗、无版本检测**的 iOS 端 IPA 签名与安装工具。在手机上独立完成：Apple ID 签名、证书签名、IPA 安装与续签提醒。UI 严格按《IPA 签名管理工具 · UI 规格说明书》实现（三 Tab：应用 / 证书 / 设备）。

> 底层签名能力基于开源项目 [Feather](https://github.com/claration/feather)（GPLv3）的 Zsign 管线，Apple ID 认证栈来自 [SideStore/AltSign](https://github.com/SideStore/AltSign)。界面与交互为按规格书的独立实现。

## 功能清单

### 应用页（Tab 1，默认落地页）
- 三段分段控件：**已导入 / 已签名 / 已安装**，整宽 16pt 边距，标题随段切换
- 常驻主操作「导入 IPA」（实心胶囊，文件/URL 两种方式）
- 已导入：原始 IPA 只读不可变；操作弹窗 = 签名 IPA / 查看描述 / 导出 / 删除；多选批量删除导出
- 已签名：倒序 + 去重（源 IPA+BundleID+App 名）；到期倒计时徽章（剩 3 天绿/剩 2 天橙/今天红）+ 一键续签；临期横幅
- 已安装：经配对文件通道读取本机 App 列表（无配对文件时引导态）；打开 / 卸载（二次确认）

### 签名流程（规格书 §2.3/§2.4）
- 配置页：Bundle ID（正则红字校验）/ App 名 / 最低系统版本 / 移除跳转 / 移除插件 / 移除手表 / 开启文件访问 / 证书选择（未选红色高亮+引导）
- 临时副本原则：顶部常驻「正在处理临时副本 · XXX 的副本，原始文件不受影响」
- **注入插件危险强提醒**：danger 描边卡片 → 阻断式风险确认弹窗 → 吸顶警示条 + 主按钮变「注入并签名」
- 过程页：吸顶进度条（解析→校验→配置→注入/移除→重签名→打包）+ 28pt 百分比 + **固定屏高 55% 的内存日志区**（等宽 12pt、级别着色、自动滚底、环形 2000 行不落盘、退出即释放）
- 终态三按钮：安装 / 导出 / 完成（「已生成已签名副本」）；失败：错误摘要 + 重试/查看完整日志/关闭；取消二次确认且真取消管线

### 证书页（Tab 2）
- 类型徽标：UDID 证书（蓝）/ Apple ID 证书（紫）/ 企业证书（琥珀）
- 列表：名称、徽标、Team ID、序列号、有效期起止与剩余天数（≤30 天警示色「即将过期」；过期危险色「已过期」且禁用于签名）
- 导入：类型选择（UDID/Apple ID/企业）→ 表单 → 解析校验（密码错误/已过期/无法解析/UDID 不匹配逐项报因）→ 成功高亮 2 秒
- 详情页：证书（Subject/Issuer/SHA-1 指纹/绑定 UDID/entitlements 摘要）+ 描述文件（Name/UUID/TeamID/AppID/设备数/过期）
- 导出 P12（分享面板）；删除二次确认（被引用时提示 N 个应用在用）

### Apple ID 免费签名
- 登录（GSA + 双重认证验证码；凭据只发苹果服务器，可选 Keychain 保存）
- 自动完成：注册设备 UDID（需配对文件）→ 创建/复用开发证书 → 注册 App ID → 拉描述文件 → 一键签名
- 名额管理：App ID 占用（x/3）+ 删除闲置描述文件释放名额
- 续签：第 5 天本地通知 + 「立即续签」（拉新描述文件重签重装）

### 设备页（Tab 3）
- 顶部状态卡（设备名/机型/配对状态点）；设备信息（型号/iOS 版本/UDID 复制/架构/开发者模式指引）
- 存储进度条（>90% 警示色）；网络状态点（Wi-Fi/蜂窝/USB）；App 概况（本工具签名数量 + 最近 3 条）
- 右上齿轮进设置（外观三态 / 安装方式 / 配对文件 / 诊断日志 / 重置）

### 安装管线（根治 Feather 静默卡死）
- 全程日志：打包→服务器启动→**链路自检**（先自拉清单，TLS 失效当场报）→itms 触发→清单/包体传输→安装进度→完成
- 12 秒看门狗：iOS 没来取清单直接报错 + 排查建议
- 固定 200pt 滚屏日志面板（可复制/导出）；设置里有全屏诊断日志页

### 界面规范
- 浅色/深色双主题（跟随系统/强制浅色/强制深色），全部语义色 token（GeekTheme）
- iPhone 横竖屏 + iPad 全方向自适应；iOS 16+（iPhone 8 及以后全系 + 近 5 年 iPad）

## 构建（云端，无需 Mac）

1. 把代码推到你自己的 GitHub 私有仓库（可用根目录 `推送并构建.ps1`）
2. Actions → `Build geekIpa IPA` → 完成后下载 Artifacts 里的 `geekIpa-ipa`
3. 本地有 Mac 则直接 `make iphoneos`，产物 `packages/geekIpa.ipa`

## 安装与首次使用

1. 用爱思/现有签名工具给 `geekIpa.ipa` 签名安装（**有付费/企业证书就用证书装**，不占免费 Apple ID 的 3 个名额）
2. 打开 → 设备页 → 齿轮 → 安装方式 → 导入配对文件（电脑爱思/iTunes 导出一次）
3. 证书页 → 导入证书（或 Apple ID 登录自动生成）
4. 应用页 → 导入 IPA → 签名 → 安装
